# Gestor de Aluguéis

**Status do projeto:** Em desenvolvimento

## Tecnologias Aplicadas
* Java (Linguagem principal)
* Java Swing (Interface Gráfica Desktop)
* MySQL (Banco de Dados Relacional)
* JDBC (Conexão e persistência de dados)

## Time de Desenvolvedores
* [André Oliveira]

## Objetivo do Software
O Gestor de Aluguéis é um sistema desktop desenvolvido para facilitar e automatizar a administração de propriedades. O seu principal objetivo é fornecer uma ferramenta centralizada onde administradores podem gerenciar imóveis, locatários, contratos de aluguel e o fluxo de pagamentos mensais, garantindo a integridade e a organização dos dados.

## Funcionalidades do Sistema (Requisitos)
* Autenticação de utilizadores (Login).
* Registo, leitura, atualização e exclusão (CRUD) de Locatários e Imóveis.
* Gestão e vinculação de Contratos de aluguel.
* Registo de Pagamentos vinculados aos contratos ativos.
* Painel central (Dashboard) com resumo de arrecadação e alertas de pendências.
* Persistência de dados em tempo real utilizando banco de dados MySQL.
